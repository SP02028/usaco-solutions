## Problem

Practice program (not a judge problem): count digit triples (a, b, c) from 1–9 with a + b + c = 10 and a·b·c + 9 = ab + bc + ca, printing each one.

## Approach

- Brute force all 9³ triples and test both equations.

## Complexity

- **Time:** O(9³)
- **Space:** O(1)

## Concepts

Brute Force
