# Helpful Maths

**Source:** [Codeforces 339A — Helpful Maths](https://codeforces.com/contest/339/problem/A)  
**Difficulty:** Codeforces rating 800  
**Verified:** ✅ Passes all 21 official Codeforces tests that are published in full.

## Problem

Rearrange the summands of a sum of 1s, 2s and 3s (such as "3+2+1") into non-decreasing order.

## Approach

- Extract the digits, sort them and join them with '+'.

## Complexity

- **Time:** O(n log n)
- **Space:** O(n)

## Concepts

Sorting, Strings
