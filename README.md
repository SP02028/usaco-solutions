# USACO Solutions Repository

A comprehensive collection of competitive programming solutions from USACO (USA Computing Olympiad) and Codeforces contests. This repository contains 330+ problem solutions implemented in Java, showcasing various algorithms and data structures.

## 📊 Repository Stats

- **Total Problems**: 330+
- **Total Solutions**: 347+ Java implementations
- **Competitions**: USACO (Bronze, Silver, Gold, Platinum), Codeforces
- **Language**: Java
## 🎯 Purpose

This repository serves as:
- A personal archive of competitive programming solutions
- A reference for common algorithms and problem-solving techniques
- A portfolio demonstrating problem-solving skills and code quality
- A resource for others learning competitive programming

## 📁 Repository Structure

Each problem is organized in its own directory containing:
- **Source Code**: Java solution file(s)
- **README.md**: Problem description, approach, complexity analysis, and key concepts

```
problem-name/
├── ProblemName.java    # Solution implementation
└── README.md           # Problem documentation
```

## 🚀 How to Run Solutions

### Prerequisites
- Java Development Kit (JDK) 11 or higher
- Command line or IDE (IntelliJ IDEA, Eclipse, VS Code)

### Running a Solution

1. **Navigate to the problem directory**:
   ```bash
   cd "problem-name"
   ```

2. **Compile the Java file**:
   ```bash
   javac ProblemName.java
   ```

3. **Run with standard input**:
   ```bash
   java ProblemName < input.txt
   ```

4. **For USACO-style problems** (file I/O):
   - Ensure input file (e.g., `problemname.in`) is in the same directory
   - Run: `java ProblemName`
   - Output will be written to `problemname.out`
