## Problem

Practice program (not a judge problem): run breadth-first search over a small hard-coded graph and print the visit order.

## Approach

- Standard BFS with a queue and a visited array, starting a new search from each unvisited vertex.

## Complexity

- **Time:** O(V + E)
- **Space:** O(V)
