# Distinct Numbers

**Source:** [CSES Problem Set — Distinct Numbers](https://cses.fi/problemset/task/1621)  
**Verified:** ⚪ Not verified automatically: CSES does not publish its test data.

## Problem

Count the number of distinct values in a list of n integers.

## Approach

- Insert every value into a HashSet and print its size.

## Complexity

- **Time:** O(n)
- **Space:** O(n)

## Concepts

Hashing, Sets
