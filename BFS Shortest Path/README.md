# BFS Shortest Path

**Source:** Practice program (not a judge problem)  
**Verified:** ⚪ Practice program with hard-coded input; nothing to verify against.

## Problem

Practice program (not a judge problem): find the unweighted shortest-path distance between two vertices of a small hard-coded graph.

## Approach

- BFS from the source storing dist[] and parent[] for every vertex; the distance to the destination is printed.

## Complexity

- **Time:** O(V + E)
- **Space:** O(V)
